## 二、既有台式食譜簡化為懶人家常版（7 道）

- [ ] 改寫「台式三杯雞」（`spec-ytower-tefal-29-three-cup-chicken`）：改為免站鍋爆炒、全部入鍋鎖蓋 `雞／鴨／豬` 12 分 ➔ 開蓋拌九層塔收汁
- [ ] 簡化「滑嫩宮保雞丁」（`spec-ytower-tefal-19-kung-pao-chicken`）：改去骨雞腿丁、去掉蛋白上漿，精簡調味料與步驟
- [ ] 簡化「養樂多滷肉／古早味控肉」（`tw-braised-pork-belly`）：改免乾煎、汆燙後全部入鍋鎖蓋 `雞／鴨／豬` 壓透（乾煎改選配）
- [ ] 簡化「古早味滷肉燥」（`tw-minced-pork-sauce`）：改免先開蓋爆炒，全部入鍋鎖蓋滷透
- [ ] 簡化「滷豬腳／花生豬腳」（`tw-braised-pork-trotters`）：去掉炒糖色步驟，改一鍋入鍋 `牛／羊` 壓透
- [ ] 簡化「暖身麻油雞」（`tw-sesame-oil-chicken`）：改為免站鍋爆炒版本（薑片麻油墊底直接壓，爆香改選配）
- [ ] 簡化「紅燒牛肉麵／滷牛腱」（`tw-beef-noodle-soup`）：去掉先煎牛肉再撈出步驟，改汆燙後全部入鍋（豆瓣醬放最上層防焦底）
