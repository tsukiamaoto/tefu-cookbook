## 跨國看片小撇步
1. **開啟雙語／繁中翻譯字幕**：在 YouTube 影片右下角開啟 `CC 字幕` ➔ 點擊齒輪 `字幕` ➔ `自動翻譯` ➔ 選擇 `中文（繁體）`，大多數日、韓、英、法、俄、西語食譜影片都能無障礙看懂步驟與克數。
2. **時間與模式換算**：看到海外影片使用 **Cookeo / Turbo Cuisine / ラクラ・クッカー / CY601** 時，直接對照 [domestic-and-international-methods.md](./domestic-and-international-methods.md) 底部「異機種轉譯對照表」套進 CY625870 即可（記得 CY625870 舒肥最低溫為 **58°C**、咖哩塊／濃醬一樣要開蓋後放）。
