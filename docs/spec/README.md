# Tefal 特福鮮呼吸智能萬用鍋（CY625870）參考資料索引

本目錄整理 **Tefal 法國特福鮮呼吸智能萬用鍋 CY625870（星辰銀）** 的官方規格、海內外實際操作經驗、深度煮法參數庫、料理網站與 YouTube 影音教學，作為 `tefu-cookbook` 食譜建立與模式轉換的參考規格。

---

## 機型基本規格速查

| 項目 | 規格／說明 |
| --- | --- |
| 台灣型號 | **CY625870**（星辰銀）／同系列異色款 **CY625170**（極地白） |
| 國際同系列名稱 | Tefal **Home Chef Smart** / **Home Chef Smart Pro**（CY625 / CY625D / CY601 系列） |
| 容量與內鍋 | 5L 容量、3.5mm 厚釜 5 層高效導熱 **陶晶球釜內鍋**（62° 黃金對流角）；可搭配 304 不鏽鋼內鍋替換 |
| 核心技術 | **鮮呼吸動態變壓科技**（10–70 kPa 交替，每分鐘變壓 2 次幫食材入味）＋ 18 道安全防護 ＋ 自動洩壓 |
| 料理模式 | **22 種以上自動烹調行程**，涵蓋壓力燉煮、舒肥（58–90°C）、爆炒煎烤（150°C）、蒸煮／一鍋兩菜、收汁／醬燒、高低溫慢燉、烘烤（120–150°C）、DIY（60–150°C）、煮飯／煮粥等 |
| 面板操作邏輯 | **左側無壓／特殊行程**：上蓋免鎖定或開蓋操作<br>**右側壓力烹調**：上蓋手把須順時鐘鎖定，支援「中途加料」與「自動洩壓」 |
