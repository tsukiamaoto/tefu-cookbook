# 燉羊膝

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 法國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.21–22） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 9 小時 30 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `低溫慢燉` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，設定 20 分鐘；預熱後煎羊膝 5 分鐘、炒蔬菜 5 分鐘後按「取消」）→ `低溫慢燉`（70°C，蓋上不鎖，9 小時）→（選配）`收汁／醬燒`（110°C，開蓋，10 分鐘） |

> **官方料理簡介**：法式經典「燉羊膝」可以很米其林也能很鄉村；拍上麵粉的羊膝兩面煎得金黃，與番茄、洋蔥、紅酒一同，用低溫慢慢燉煮好讓食材中的精華一一釋出。

## 二、製作步驟（官方原文逐步整理）

1. 用一塊乾淨的濕布抹拭小羊膝，沾上調味過的麵粉，拍掉多餘粉末。
2. 在內鍋中加入2tbsp橄欖油。
3. 選擇「爆炒煎烤」模式。設定時間為 20 分鐘。按下「開始」。
4. 當特福智能萬用鍋發出提示音時，油已熱。煎每顆小羊膝5分鐘，中間不時翻動，直到表面變金黃色，取出備用。
5. 原鍋加入2tbsp橄欖油，放入洋蔥、紅蘿蔔、蒜，炒5分鐘。
6. 加入番茄、紅酒、高湯、奧勒岡葉和檸檬皮屑拌勻。
7. 放回小羊膝，以醬汁和蔬菜覆蓋完全。按「取消」。
8. 蓋上上蓋，但不鎖上。選擇「低溫慢燉」功能，設定時間9小時，按下「開始」。
9. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋取出小羊膝。
10. 若希望醬汁變得濃稠，選擇「收汁／醬燒」功能，在打開上蓋情況下讓醬汁蒸發10分鐘，慢慢加入麵粉和水混合的麵粉糊，直到達到理想的濃稠度。按「取消」。可配米飯、義大利麵或薯泥享用。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 也可使用羊膝。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：本道料理全程使用無壓特殊行程（不需洩壓）。`爆炒煎烤`（150°C，預熱可長達 5 分鐘）與`收汁／醬燒`（110°C）皆須**開蓋**操作；`低溫慢燉`（70°C）則須**蓋上上蓋，但不要鎖上**。
- **烹調與護鍋提醒**：
  - 官方食材表列橄欖油為 `2tbsp`，而步驟 2（煎羊膝）與步驟 5（炒蔬菜）分別寫明加入 `2tbsp` 橄欖油，且步驟 10 收汁時可視需求另備少量麵粉與水混合成麵粉糊，備料時可先預留。
  - `爆炒煎烤`翻動小羊膝與拌炒蔬菜時請使用矽膠或木質鍋鏟，避免刮傷不沾球釜內鍋塗層。
