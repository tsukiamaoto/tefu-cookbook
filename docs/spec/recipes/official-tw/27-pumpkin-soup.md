# 南瓜湯

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 美國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.61–62） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 30 分鐘 |
| 官方份量 | 6 人份 |
| 官方主打模式 | `煮／燉湯品` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，設定 5 分鐘：預熱後炒煙燻肉 3 分鐘＋加蔥炒 2 分鐘，完成按「取消」）→ `煮／燉湯品`（增壓快煮 30kPa，鎖蓋，設定 20 分鐘，完成並排氣洩壓後按「取消」） |

> **官方料理簡介**：美國最受歡迎的感恩節菜餚之一，先將南瓜烘烤後再與高湯一起熬煮成湯，也可加入堅果增加風味，隨著食譜越受歡迎作法也跟著多元化。

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 橄欖油 | 1tbsp |
| 蔥（直切再切絲） | 2棵 |
| 西洋芹（切片） | 2根 |
| 蔬菜高湯或雞湯（也可使用水） | 3杯 |
| 煙燻肉（切丁） | 100g |
| 南瓜（去皮籽，切約1cm大小） | 500g |
| 馬鈴薯（150g切丁） | 1顆 |
| 鹽和黑胡椒 | 適量 |

---

## 二、製作步驟（官方原文逐步整理）

1. 油倒入內鍋中。選擇「爆炒煎烤」模式。設定時間為5分鐘。按下「開始」。
2. 當特福智能萬用鍋發出提示音時，放入煙燻肉炒3分鐘，或直至肉變脆。期間不時攪動。
3. 加入蔥再炒2分鐘，期間不斷攪拌。當特福智能萬用鍋發出提示音時，按「取消」。
4. 加入其餘材料，蓋上上蓋並鎖緊。
5. 選擇「煮／燉湯品」模式。將時間設定為20分鐘。按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
6. 當模式完成並排氣洩壓後，按「取消」。
7. 打開鍋蓋，倒出用調理機攪拌至滑順，然後按個人口味調整鹽和黑胡椒份量。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 煙燻肉也可使用培根替代。
- 2. 蔥可用洋蔥丁1/2顆替代，具不同風味。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：第一階段「爆炒煎烤」（150°C，預熱可長達 5 分鐘）為開蓋無壓行程，待提示音響起再下煙燻肉，炒完記得先按「取消」結束行程；第二階段「煮／燉湯品」為增壓快煮壓力行程（原廠預設 30kPa／20 分鐘，壓力可調 20–50kPa），須**蓋上上蓋並鎖緊**，完成並排氣洩壓後再按「取消」開蓋。
- **烹調與護鍋提醒**：開蓋拌炒煙燻肉與蔥絲時請使用耐高溫矽膠鏟或木鏟，保護不沾內鍋塗層；步驟 7 攪打濃湯時請依官方步驟先將湯料倒出至調理機（或另行放至適當容器）再攪打，切勿直接在內鍋中使用金屬攪拌棒以免刮傷內鍋。
