## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 白肉魚片（每片150g） | 4片 |
| 生抽 | 4tbsp |
| 台灣綠蘆筍（削皮切半） | 2束 |
| 薑末（去皮） | 4tsp |
| 檸檬汁 | 1顆 |
| 二砂糖 | 1tsp |
| 蔥（切細絲） | 2棵 |
| 芫荽 | 1/2杯 |

---

## 二、製作步驟（官方原文逐步整理）

1. 將每片魚柳的魚皮略煎2-3次。準備烘焙紙或錫箔紙四大張。（一片包一張）
2. 檸檬汁、醬油和二砂糖混合。
3. 烘焙紙上鋪上綠蘆筍和蔥絲，再擺上魚柳，再加上薑末和芫荽，並淋上1/4份量的醬汁後包覆起來。（重複四次）
4. 內鍋倒入2杯水，將托架放入，再放上紙包魚。蓋上上蓋，並鎖緊。
5. 選擇「蒸／一鍋兩菜」模式。將時間設定為12分鐘。按下「開始」。
6. 當模式完成並排氣洩壓後，按「取消」。
7. 取出紙包魚上碟，再淋上醬汁享用。

## 三、官方小撇步！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 鱈魚或比目魚非常適合蒸煮可配白飯享用。
- 2. 不煎魚皮也可，口感會較清爽。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：「蒸／一鍋兩菜」為壓力行程（預設 10 kPa／8 分鐘），操作時須**蓋上上蓋並鎖緊**，並將時間調整為 **12 分鐘**；行程結束後須待**排氣洩壓完成**，再按「取消」開蓋。
- **烹調與護鍋提醒**：內鍋須先倒入 2 杯水再置入托架與紙包魚，包覆時封口確實摺緊以鎖住香氣與醬汁；拆開紙包時請注意滾燙蒸氣。若欲直接以本鍋執行步驟 1 略煎魚皮，可使用開蓋的「爆炒煎烤」（150°C）並以非金屬鍋鏟翻面以保護內鍋塗層，亦可依小撇步省略煎魚皮步驟。
