# 蘑菇義大利燉飯

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 義大利 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.73–74） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 22 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `快煮米飯` |
| 完整行程串接 | `爆炒煎烤`（開蓋，150°C，設定 5 分鐘；炒洋蔥 4 分鐘＋炒義大利米與蘑菇 1 分鐘後按取消） → `快煮米飯`（鎖蓋，預設 30kPa，時間設定 14 分鐘，完成並排氣洩壓後按取消） → `爆炒煎烤`（開蓋，150°C，設定 3 分鐘，拌入奶油、帕瑪森起司與奧勒岡葉調味後按取消；依 Tips 亦可直接趁熱拌勻） |

> **官方料理簡介**：與義大利麵共同享譽國際的燉飯，一樣是義大利全國媽媽們的拿手菜色，帶著奶油香氣及靠起司構成的質地讓人百吃不厭~~

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 橄欖油 | 2tbsp |
| 義大利米 | 1 1/2杯 |
| 雞高湯 | 2 1/4杯 |
| 奶油 | 50g |
| 奧勒岡葉 | 1/4杯 |
| 洋蔥 (切碎) | 1顆 |
| 蘑菇(切片) | 200g |
| 白酒 | 1/3杯 |
| 帕瑪森起司 | 50g |
| 鹽和黑胡椒 | 適量 |

---

## 二、製作步驟（官方原文逐步整理）

1. 油倒入內鍋中。
2. 選擇「爆炒煎烤」模式。設定時間為5分鐘。按下「開始」。
3. 當特福智能萬用鍋發出提示音時，放入洋蔥炒4分鐘，期間不斷攪拌，直至金黃色。
4. 加入義大利米和蘑菇，然後繼續翻炒1分鐘。按「取消」。
5. 加入雞高湯和白酒。蓋上上蓋並鎖緊。
6. 選擇「快煮米飯」模式。將時間設定為14分鐘。按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
7. 當特福智能萬用鍋發出提示音並完成排氣洩壓後，按「取消」。
8. 加入奶油和帕瑪森起司，選擇「爆炒煎烤」模式。設定時間為3分鐘。按下「開始」。
9. 加入奧勒岡葉，並以鹽和黑胡椒調味。按「取消」。即可享用。

---

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 最後奶油和帕瑪森起司可直接趁熱拌勻，不需煎炒。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：前後兩段「爆炒煎烤」（150°C，預熱可長達 5 分鐘）皆須**開蓋**操作，並於切換模式前按「取消」；中間「快煮米飯」增壓快煮行程（30kPa／預設 14 分鐘）務必**蓋上上蓋並鎖緊**，提示音響且完成排氣洩壓後再按「取消」開蓋。
- **烹調與護鍋提醒**：步驟 8 若啟動「爆炒煎烤」融化奶油與帕瑪森起司，須全程以矽膠匙或木匙持續拌勻防黏底；若擔心鍋溫過高焦底，建議直接參考官方 Tips，利用剛洩壓起鍋的餘溫趁熱拌勻奶油與起司。
