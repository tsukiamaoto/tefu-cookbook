# 法式蘑菇豬柳

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 法國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.19–20） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 35 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `蒸/一鍋兩菜` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，15 分鐘）→ `蒸/一鍋兩菜`（壓力模式，10kPa，鎖蓋，15 分鐘）→ `收汁/醬燒`（110°C，5 分鐘；原廠規格為開蓋，本頁步驟 9 原文印為鎖蓋） |

> **官方料理簡介**：法國菜在精雕細琢之外尚存在著樸實自然、充滿地方風情特色的鄉村菜。搭配蔬菜並簡單調味的完整肉塊端上桌，正是家人連繫情感的好時光。

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 豬里肌 (整塊) | 800g-1000g |
| 橄欖油 | 2tbsp |
| 洋蔥 (切丁) | 1顆 |
| 蒜 (拍碎) | 3瓣 |
| 白酒 | 1/2杯 |
| 雞湯 | 1杯 |
| 蘑菇 (切四塊) | 200g |
| 菠菜 | 2撮 |
| 鹽和黑胡椒 | 適量 |

---

## 二、製作步驟（官方原文逐步整理）

1. 油倒入內鍋中。選擇「爆炒煎烤」模式。設定時間為15分鐘。按下「開始」。
2. 當特福智能萬用鍋發出提示音時，放入豬肉煎約8分鐘，直至表面呈金黃色。取出備用。
3. 加入洋蔥和蒜末炒2分鐘，再放入蘑菇炒3分鐘，期間不斷攪拌。
4. 放回豬肉，加入白酒和雞湯。當特福智能萬用鍋發出提示音時，按「取消」。
5. 以鹽和黑胡椒調味後，蓋上上蓋並鎖緊。
6. 選擇「蒸/一鍋兩菜」模式。將時間設定為15分鐘。按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
7. 當模式完成洩壓後，按「取消」。
8. 取出豬柳後放在碟上備用。用錫箔紙覆蓋。
9. 選擇「收汁/醬燒」功能。設定時間為5分鐘。蓋上上蓋並鎖緊。按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
10. 最後一分鐘放入菠菜，攪拌均勻。當特福智能萬用鍋發出提示音，按「取消」，打開上蓋。
11. 菠菜與蘑菇鋪於盤子底部。豬柳切片，擺放於蔬菜上面，再淋上高湯，然後搭配米飯享用。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 菠菜也可換成其他的蔬菜。
- 2. 豬里肌可先用棉繩綑綁，煮後形狀會較漂亮。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`爆炒煎烤`（150°C，開蓋，預熱可長達 5 分鐘）須開蓋煎炒；`蒸/一鍋兩菜`（10kPa，15 分鐘）為低壓壓力行程，須**蓋上上蓋並鎖緊**，行程結束並**完成洩壓後**按「取消」開蓋；最後一段 `收汁/醬燒`（110°C，5 分鐘）雖於本頁步驟 9 原文印為「蓋上上蓋並鎖緊」，但依同本手冊 p.4–5 原廠行程規格表，`收汁/醬燒` 為無壓**開蓋**模式，實作時請保持開蓋收汁，既能有效蒸散水分濃縮醬汁，也便於在最後 1 分鐘放入菠菜拌勻。
- **烹調與護鍋提醒**：步驟 8 取出豬柳後以錫箔紙覆蓋靜置，能鎖住肉汁讓切片更軟嫩多汁；步驟 4 倒入白酒與雞湯時可使用木杓或耐熱矽膠鏟輕刮鍋底焦香精華融入湯汁，切勿使用金屬器具以免刮傷不沾內鍋塗層。
