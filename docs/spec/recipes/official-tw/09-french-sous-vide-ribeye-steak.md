# 法式舒肥肋眼牛排

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 法國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.25–26） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |

> **官方料理簡介**：減醣一族的理想菜單，不只雞胸肉、里肌肉，事實上富含鐵質的牛排更受推崇！舒肥後的牛排口感質地更多汁鮮美，且擁有最完整的營養與自然原味。

| 巴西里葉碎 | 1撮 |

## 二、製作步驟（官方原文逐步整理）

1. 將牛排分別放入獨立的密封袋中，每袋內分別加1tbsp有鹽奶油。在內鍋中加水，將每個密封袋半浸於水中，讓袋中空氣被擠出，然後密封封口。
2. 選擇「舒肥料理」功能，將溫度設定為58°C，時間設定為 4小時，即可煮出5分熟效果。（58°C=五分熟，63°C=六分熟，69°C=全熟）
3. 關上上蓋但不要鎖上，然後按「開始」。
4. 模式完成後，可以將牛排放入冰箱內，方便需要時取出使用，或馬上繼續進行以下的煎牛排步驟。將鍋內水倒出，並抹乾內鍋。
5. 擦乾牛排，以鹽和黑胡椒調味。
6. 在內鍋中加入適量油。選擇「爆炒煎烤」模式。並將時間設定為15分鐘。按「開始」。
7. 當特福智能萬用鍋發出提示音時，表示油已熱。將牛排兩面各煎10-15秒。然後取出靜置。
8. 內鍋放入蒜和紅蔥頭，加入適當的奶油。放入蘑菇炒約3分鐘。加入酒收乾，再加入鮮奶油、伍斯特醬和第戎芥末醬。煮滾後倒入碗中，並灑上巴西里葉碎。
9. 將蘑菇醬汁淋在牛排上享用。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：本道料理全程為無壓特殊行程（不需洩壓）。`舒肥料理`（可調 58–90°C）須**關上上蓋但不要鎖上**；後續`爆炒煎烤`（150°C，預熱可長達 5 分鐘）煎牛排與炒蘑菇醬須**開蓋**操作，且啟動前務必先將鍋內舒肥水倒淨並完全抹乾內鍋。
- **烹調與護鍋提醒**：
  - 官方表列兩次有鹽奶油，分別用於步驟 1 舒肥密封袋（`2tbsp`，每袋各 `1tbsp`）與步驟 8 炒蘑菇醬汁（`1tbsp`）；牛排下鍋煎烤前務必徹底擦乾表面水氣，才能在每面 10–15 秒內快速上色且不讓內部過熟。
  - 翻面煎牛排與拌炒蘑菇醬時請使用矽膠夾或木質鍋鏟，保護不沾內鍋塗層；舒肥水排氣封口時請選用耐熱食品級密封袋並確認袋口完全浸水外緣密合。
