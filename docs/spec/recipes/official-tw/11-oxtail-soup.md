| 項目 | 內容 |

> **官方料理簡介**：牛尾營養價值極高，經燉煮會使強健骨骼的膠質及維持肌膚彈性的膠原蛋白隨著烹飪時長而釋放，採用清燉方式身體更無負擔。

---

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 牛尾 | 500g |
| 薑片 | 4-6片 |
| 青蔥&芫荽 | 1撮 |
| 米酒 | 2tbsp |
| 水 | 適量 |
| 鹽 | 5g |

---

## 二、製作步驟（官方原文逐步整理）

1. 用另一個鍋具加冷水、一半份量的薑和米酒，汆燙牛尾（煮滾後再煮2分鐘）瀝乾水分備用。此步驟可去除牛尾的血水和雜質。
2. 將前步驟的牛尾放入內鍋，加水直至覆蓋牛尾。
3. 加入青蔥、薑和米酒。
4. 蓋上上蓋並鎖緊。
5. 選擇「牛／羊」，將時間設定為45分鐘，然後按下「開始」。
6. 當模式完成並排氣洩壓後，打開上蓋，加入鹽和芫荽。您亦可選擇在上碟後才加上芫荽。

---

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 牛尾也可使用帶皮的牛尾，會有不同層次的口感。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`牛／羊`為增壓快煮行程（預設 60kPa／30 分鐘），本食譜須手動將時間**調整為 45 分鐘**，並確認**蓋上上蓋並鎖緊**；行程完成後必須待排氣洩壓完全才可開啟上蓋。
- **烹調與護鍋提醒**：
  - 薑片與米酒須分兩次使用：一半用於步驟 1 另鍋冷水汆燙去腥去雜質，剩餘一半於步驟 3 與青蔥一同入內鍋清燉；鹽與芫荽（香菜）留至壓煮洩壓開蓋後再加，能維持湯頭清澈並保留芫荽清香。
  - 加水覆蓋牛尾時，請留意內鍋最高水位標線，並於擺放帶骨牛尾時輕放以免碰撞刮傷不沾內鍋塗層。
