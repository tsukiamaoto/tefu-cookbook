# 越式風味牛肉粉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 越南 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.15–16） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 3 小時 10 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `高溫慢燉` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，4 分鐘）→ `高溫慢燉`（90°C，蓋上不鎖，3 小時）→ `爆炒煎烤`（150°C，開蓋，煮熟大白菜並勾芡至濃稠後手動按「取消」） |

> **官方料理簡介**：米線、河粉都是越南經典菜色，以台灣常見的台式米粉，稍加些創意，一碗帶有越式風味卻符合台灣人口味的美味料理輕鬆完成!

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 植物油 | 2tbsp |
| 香茅 (切碎) | 2根 |
| 牛肩胛肉小排或牛腱 (約3cm大小) | 500g |
| 紅味增 | 1/3杯 |
| 煮熟的細米粉 | 440g |
| 芫荽 (切碎) | 2tbsp |
| 洋蔥絲 | 2顆 |
| 薑末 (去皮) | 20g |
| 水 | 1000ml |
| 大白菜 (切細絲) | 300g |
| 玉米粉 | 1tbsp |
| 薄荷 (切碎) | 2tbsp |

---

## 二、製作步驟（官方原文逐步整理）

1. 在內鍋中加入少量植物油。選擇「爆炒煎烤」功能，並將時間設定為 4分鐘，按「開始」。
2. 當特福智能萬用鍋發出提示音，表示油已燒熱。加入洋蔥絲、香茅碎和薑末炒4分鐘，期間不斷攪拌至呈金黃色。發出提示音時，按「取消」。
3. 加入牛肉、水、紅味增攪拌均勻。
4. 關上上蓋但不要鎖上。
5. 選擇「高溫慢燉」功能，設定時間3小時，按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
6. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋。
7. 選擇「爆炒煎烤」功能，按「開始」。加入大白菜煮熟。
8. 放入細米粉，再將玉米粉與1tbsp水混合，拌入鍋中，煮至湯汁變得濃稠。
9. 按「取消」。拌入芫荽和薄荷，倒入碗中享用。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 喜歡大白菜軟爛口感者，可將大白菜一開始就加入，省略步驟7。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：前後兩段 `爆炒煎烤`（150°C，預熱可長達 5 分鐘）皆須**開蓋**操作；中段 `高溫慢燉`（90°C，3 小時）為無壓特殊行程，須**關上上蓋但不要鎖上**，時間到無須洩壓，按「取消」即可開蓋。
- **烹調與護鍋提醒**：步驟 3 放入紅味增後建議充分拌開溶解再開始慢燉，避免味噌沉積鍋底；步驟 8 倒入玉米粉水（1tbsp 玉米粉＋1tbsp 水）時請以木杓或矽膠杓持續輕拌至湯汁濃稠，並記得依步驟 9 手動按「取消」停止加熱。
