# 椰香南瓜綠咖哩牛

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 泰國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.69–70） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 6 小時 10 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `低溫慢燉` |
| 完整行程串接 | `爆炒煎烤`（開蓋，150°C，設定 10 分鐘；預熱後炒洋蔥蒜頭 3 分鐘＋炒咖哩醬、麵粉、番茄醬約 3 分鐘＋加椰漿等煮滾後按取消） → `低溫慢燉`（蓋上不鎖，70°C，設定 6 小時） |

> **官方料理簡介**：綠咖哩的「綠色」來自大量新鮮辣椒和各式香料，讓綠咖哩辛香十足，加入椰奶會讓口感溫順、降低青辣椒的刺激度。再使用低溫慢煮維持食材營養及風貌上的完整度。

## 二、製作步驟（官方原文逐步整理）

1. 在內鍋中加入少許植物油。選擇「爆炒煎烤」模式，設定時間10分鐘。按下「開始」。
2. 當特福智能萬用鍋發出提示音時，油已熱。加入洋蔥和蒜頭，炒3分鐘。
3. 直至香味釋出。加入咖哩醬、麵粉和番茄醬翻炒約3分鐘。
4. 加入椰漿、雞湯、檸檬汁、糖、魚露、鹽和胡椒粉，拌勻煮滾。按「取消」。
5. 加入牛肉和南瓜，蓋上上蓋，但不鎖上。
6. 選擇「低溫慢燉」功能，設定時間6小時，按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
7. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋。
8. 上碟後撒上芫荽碎做裝飾。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 可用市售泰式綠咖哩醬包，使用2包(共100g)。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：前期「爆炒煎烤」（150°C，預熱可長達 5 分鐘）全程須**開蓋**翻炒，待拌勻煮滾後須先按「取消」；進入左側無壓行程「低溫慢燉」（70°C，6 小時）時**蓋上上蓋但不鎖上**，全程不加壓，提示音響起按「取消」即可直接打開上蓋，無須洩壓。
- **烹調與護鍋提醒**：步驟 3–4 加入麵粉與椰漿後醬汁較易附著鍋底，建議全程使用耐高溫矽膠匙或木匙充分翻炒拌勻再進行 6 小時慢燉，避免金屬器具刮傷內鍋塗層。
