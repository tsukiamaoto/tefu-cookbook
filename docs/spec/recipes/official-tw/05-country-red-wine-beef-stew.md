# 鄉村紅酒燉牛肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 法國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.17–18） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 40 分鐘 |
| 官方份量 | 3 人份 |
| 官方主打模式 | `牛/羊` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，10 分鐘）→ `牛/羊`（壓力模式，預設 60kPa，鎖蓋，30 分鐘） |

> **官方料理簡介**：法式鄉村菜餚，善用一切易取的食材，香腸與牛肉創造出更濃郁熏香的味道，加上根莖蔬菜的鮮甜，不管大人或小孩都無法抗拒其魅力!

## 二、製作步驟（官方原文逐步整理）

1. 選定「爆炒煎烤」模式。將油倒入內鍋中。時間設定10分鐘。按下「開始」。
2. 當特福智能萬用鍋發出提示音時，倒入橄欖油，並加入豬肉香腸和牛肉。炒至牛肉變色，取出備用。
3. 原鍋放入將洋蔥和蔥白放入內鍋中翻炒，炒至洋蔥呈為透明。
4. 放入紅蘿蔔翻炒。
5. 放入番茄、百里香、糖、鹽及黑胡椒翻炒。
6. 放回牛肉與香腸，加入伍斯特醬拌均勻。
7. 加入紅酒，攪拌均勻。最後放入馬鈴薯及蔥綠，攪拌到時間停止。（特福智能萬用鍋發出提示音）
8. 蓋上上蓋並鎖緊。
9. 選擇「牛/羊」。設定時間30分鐘。
10. 按「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
11. 當特福智能萬用鍋發出提示音時，完成洩壓後，按「取消」。打開上蓋。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 牛肉種類可依口味做變換。
- 2. 蔥若較粗，可將蔥白剖半後再切段。
- 3. 可用新鮮百里香 2小棵 替代。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`爆炒煎烤`（150°C，開蓋，預熱可長達 5 分鐘）須開蓋完成 10 分鐘炒料；進入 `牛/羊`（預設 60kPa，30 分鐘）壓力行程前務必**蓋上上蓋並鎖緊**，行程結束並**完成洩壓後**再按「取消」開蓋。
- **烹調與護鍋提醒**：本食譜不另加清水，由 500g 番茄出水搭配紅酒與伍斯特醬產生蒸氣，鎖蓋前請確認鍋底食材攪拌均勻未沾黏；另提醒原文食材表列有「蒜末 3 瓣」（可於步驟 3 與洋蔥、蔥白同炒爆香），步驟 5 提及之「糖」未另列於食材表，可視番茄酸度酌量添加。
