# 可樂豬肋排

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 台灣 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.27–28） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 30 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `牛／羊` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，10 分鐘）→ `牛／羊`（預設 60kPa，鎖蓋，30 分鐘，完成後排氣洩壓）→ `收汁／醬燒`（110°C，開蓋，10 分鐘） |

> **官方料理簡介**：豬肋排營養豐富又是豬肉中最鮮香的部位，無論是煲湯、紅燒、家常燉都美味。加入可樂，不僅讓肋排Q彈更能呈現漂亮的色澤。

## 二、製作步驟（官方原文逐步整理）

1. 將豬肋排切成5cm長，用冷水煮滾，藉此去除血水和雜質。（煮滾後再煮2分鐘）。
2. 在內鍋中加入油，選擇「爆炒煎烤」模式。設定時間10分鐘。當特福智能萬用鍋發出提示音時，油已熱，加入豬肋排，然後翻炒至表面變成金黃色。
3. 加入蔥白、薑和米酒，然後續炒1-2分鐘。當提示音響起，按下「取消」。
4. 利用餘溫加入生抽、老抽、蠔油拌勻，加入可樂及蔥綠。
5. 蓋上上蓋並鎖緊。
6. 選擇「牛／羊」，將時間設定為30分鐘，然後按下「開始」。當模式完成並排氣洩壓後，打開鍋蓋選擇「收汁／醬燒」，設定時間10分鐘。
7. 當時間到了，即可將豬肋排上碟，並灑上芝麻做裝飾。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`爆炒煎烤`（150°C，預熱可長達 5 分鐘）與最後的`收汁／醬燒`（110°C）皆須**開蓋**操作；中間的增壓快煮行程`牛／羊`（預設 60kPa／30 分鐘）必須**蓋上上蓋並鎖緊**，待行程結束並確認完全排氣洩壓後方可開蓋收汁。
- **烹調與護鍋提醒**：
  - 本道豬肋排官方採用高壓`牛／羊`模式（60kPa／30 分鐘）以讓帶骨肋排充分軟嫩入味；最後`收汁／醬燒` 10 分鐘期間因可樂含糖量較高，建議不時以矽膠或木質鍋鏟翻拌，避免焦糖化過度黏鍋並保護不沾球釜內鍋塗層。
  - 官方標示之「30 分鐘」對應主壓煮時間，實際完整烹調需另計汆燙、爆炒 10 分鐘、升壓洩壓及收汁 10 分鐘。
