# 慢煮巴東牛肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 印尼 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.79–80） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 4 小時 20 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `高溫慢燉` |
| 完整行程串接 | `爆炒煎烤`（開蓋，150°C，設定 15 分鐘；炒洋蔥、薑泥、蒜泥 1 分鐘＋炒巴東咖哩醬 2 分鐘＋炒牛肋條約 4 分鐘＋加 1/2 杯水煮至完全收乾＋拌入椰漿後取消） → `高溫慢燉`（蓋上不鎖，90°C，設定 4 小時） →（選用）`收汁／醬燒`（開蓋，110°C，5 分鐘） |

> **官方料理簡介**：巴東牛肉又稱為仁當牛肉，牛肉經過長久燉煮後，吸滿了香料和椰奶的精華。使用「高溫慢燉」功能讓食材更具完整性，保留更多風味營養。

---

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 牛肋條 (切成約3cm大小) | 750g |
| 洋蔥(切碎) | 1杯 |
| 薑泥 | 1tbsp |
| 蒜泥 | 1tbsp |
| 小辣椒(按個人喜好) | 1根 |
| 植物油 | 1tbsp |
| 巴東咖哩醬 | 30g |
| 全脂椰漿 | 1杯 |
| 水 | 1/2杯 |
| 椰絲 | 2tbsp |

---

## 二、製作步驟（官方原文逐步整理）

1. 內鍋中加入少許植物油。選擇「爆炒煎烤」模式。將時間設定為15分鐘。
2. 當特福智能萬用鍋發出提示音時，油已熱，隨即可加入洋蔥、薑泥、蒜泥翻炒1分鐘。
3. 加入巴東咖哩醬並不斷翻炒。煮2分鐘。
4. 加入牛肋條，然後炒約4分鐘。
5. 加入1/2杯水，拌勻然後煮至水分完全收乾。加入椰漿並拌勻。
6. 取消「爆炒煎烤」功能。關上上蓋不鎖緊。
7. 選擇「高溫慢燉」功能，設定時間4小時，按下「開始」。
8. 當程序完成後，打開上蓋，檢查醬汁的濃稠度。若希望醬汁變得濃稠，選擇「收汁／醬燒」功能，在打開上蓋情況下讓醬汁蒸發5分鐘，直到達到理想的濃稠度。(請注意，醬汁冷卻後會變得更濃稠)
9. 撒上椰絲做裝飾，並淋於飯上享用。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 可使用市售巴東咖哩醬包
- 2. 牛肋條可先用巴東咖哩醬醃漬一晚，更入味。
- 3. 步驟 5 要水分完全收乾後，再加入椰漿。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：「爆炒煎烤」（150°C，預熱可長達 5 分鐘）與最後選用的「收汁／醬燒」（110°C）皆須**開蓋**操作；「高溫慢燉」（90°C，4 小時）屬左側無壓特殊行程，須**關上上蓋不鎖緊**，全程不加壓，程序完成後即可直接開蓋無須洩壓（與增壓快煮版「巴東牛肉」的最大操作差異即在於此）。
- **烹調與護鍋提醒**：步驟 5 須將 1/2 杯水完全收乾再拌入全脂椰漿；因含有濃稠香料醬與椰漿，爆炒與開蓋收汁 5 分鐘期間建議使用耐高溫矽膠匙或木匙翻拌以護鍋並防沾黏，且醬汁冷卻後濃稠度會再提升，收汁時請保留適度濕潤。
