# 乾蔥蒜香雞肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 法國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.23–24） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 6 小時 23 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `低溫慢燉` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，18 分鐘）→ `低溫慢燉`（70°C，蓋上不鎖，6 小時）→ `收汁／醬燒`（110°C，開蓋，8 分鐘） |

> **官方料理簡介**：這道簡易的法國料理講究的是「純淨感」，雞腿主要是以法式水煮的方式來呈現，先輕煎後透過烹煮，讓辛香料與雞高湯的風味和雞腿互相融合，適合家常也適合宴會。

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 雞腿塊(去皮 & 去油脂) | 1000g |
| 蒜頭(去皮分小瓣) | 1大顆 |
| 小洋蔥或紅蔥頭 | 6-8粒 |
| 白酒 | 1/2杯 |
| 百里香 | 1小棵 |
| 百里香碎 | 1tbsp |
| 雞湯 | 3/4杯 |
| 玉米粉 | 1 1/2tbsp（原文排印作 11/2tbsp） |
| 鹽 | 1tsp |
| 白胡椒粉 | 1/2tsp |
| 植物油 | 2tbsp |
| 奶油 | 1tbsp |

---

## 二、製作步驟（官方原文逐步整理）

1. 在內鍋中加入油。
2. 選擇「爆炒煎烤」模式。並將時間設定為18分鐘。按「開始」。
3. 當特福智能萬用鍋發出提示音時，油已熱，加入雞塊煎至6-7分鐘，直至金黃色，取出備用。
4. 加入蒜和乾蔥不斷翻炒。煮3分鐘。
5. 加入白酒和原棵百里香。
6. 當特福智能萬用鍋發出提示音時，按「取消」。
7. 加入雞湯、雞塊和鹽、胡椒粉。
8. 關上上蓋，但不要鎖上。
9. 選擇「低溫慢燉」功能，設定時間6小時，按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
10. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋，取出雞塊，將玉米粉與少量水混合倒入鍋中。
11. 選擇「收汁／醬燒」功能，在打開上蓋情況下讓醬汁蒸發8分鐘，直到達到理想的濃稠度。（請注意，醬汁冷卻後會變得更濃稠）
12. 放回雞塊，按「取消」。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 也可使用整隻棒棒腿製作。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：本道料理全程皆屬無壓特殊行程（無須洩壓）。`爆炒煎烤`（150°C，預熱可長達 5 分鐘）與`收汁／醬燒`（110°C）須**開蓋**操作；`低溫慢燉`（70°C）須**關上上蓋，但不要鎖上**，啟動後畫面顯示轉圈預熱，達溫後才會開始 6 小時倒數。
- **烹調與護鍋提醒**：
  - 原食譜表另列有「奶油 1tbsp」與「百里香碎 1tbsp」，可於開鍋煎炒或收汁起鍋添香時彈性運用；玉米粉請務必先與少量冷水調勻再倒入鍋中勾芡，避免結塊。
  - `收汁／醬燒`階段醬汁濃稠度會隨冷卻上升，收汁期間請以耐熱矽膠刮刀或木匙不時輕拌鍋底，防止澱粉焦底並保護內鍋塗層。
