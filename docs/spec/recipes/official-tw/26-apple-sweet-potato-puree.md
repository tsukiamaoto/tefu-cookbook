# 蘋果甜薯蓉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 美國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.59–60） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 15 分鐘 |
| 官方份量 | 3 人份 |
| 官方主打模式 | `蒸／一鍋兩菜` |
| 完整行程串接 | `蒸／一鍋兩菜`（增壓快煮 10kPa，鎖蓋，設定 15 分鐘，完成並排氣洩壓後按「取消」開蓋） |

> **官方料理簡介**：美式沙拉常見配菜，也可是小朋友的點心或者是寶寶食譜。蘋果加熱後抗氧化多酚增加，加上地瓜及南瓜的膳食纖維，不需多加其它調味，自然鮮甜。

---

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 蘋果（對半切） | 1/2顆 |
| 地瓜（去皮切片） | 150g |
| 奶油南瓜（去皮切片） | 150g |
| 肉桂粉 | 1/4tsp |
| 水 | 150ml |

---

## 二、製作步驟（官方原文逐步整理）

1. 準備好所有材料。
2. 將水倒入內鍋中。
3. 將蒸盤放入內鍋中，鋪上烘焙紙，放入蘋果、地瓜和奶油南瓜。
4. 蓋上鍋蓋並鎖緊。選擇「蒸/一鍋兩菜」模式。將時間設定為15分鐘。
5. 按「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
6. 當模式完成並排氣洩壓後，按「取消」，打開上蓋。
7. 取出蔬菜，然後用叉子或調理機將蔬菜打成泥。當蔬菜拌勻後加入肉桂粉。
8. 攪拌時可加入少量蔬菜湯、鮮奶油或牛奶，蔬菜泥會變得更滑順。

---

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 當做寶寶食品，選擇紅肉地瓜會較濕潤。
- 2. 若是小蘋果，可使用1顆。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：「蒸／一鍋兩菜」屬於右側增壓快煮壓力行程（原廠設定 10kPa，預設時間 8 分鐘，本道需手動調為 15 分鐘），操作時須**蓋上鍋蓋並鎖緊**；行程結束後須確認完成排氣洩壓，再按「取消」並解鎖開蓋。
- **烹調與護鍋提醒**：務必先將 150ml 水倒入內鍋再放上蒸盤，避免空燒；放置與取出蒸盤時請輕拿輕放並使用防燙夾，避免刮傷不沾內鍋內壁或被高溫蒸汽燙傷。
