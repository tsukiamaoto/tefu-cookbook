# 俄式燉牛肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 俄國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.09–10） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 45 分鐘 |
| 官方份量 | 3 人份 |
| 官方主打模式 | `牛／羊` |
| 完整行程串接 | `爆炒煎烤`（150°C，開蓋，10 分鐘）→ `牛／羊`（壓力模式，預設 60kPa，鎖蓋，30 分鐘）→ `自訂行程`（70°C，鎖蓋，5 分鐘） |

> **官方料理簡介**：由法國廚師融合俄國食材、風味發想而成的美味，在當代更因使用大量的牛肉被譽為「富人料理」。不管搭配馬鈴薯泥、白飯或義大利麵，都是不能錯過的好滋味!!

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 牛肩胛肉小排 (去骨) | 600g |
| 洋蔥 (去皮切四塊) | 1/2顆 |

| 黑胡椒 | 適量 |

## 二、製作步驟（官方原文逐步整理）

1. 牛肉以鹽和黑胡椒先醃漬。
2. 選定「爆炒煎烤」模式。時間設定10分鐘。按下「開始」。
3. 當特福智能萬用鍋發出提示音時，奶油加入鍋中。
4. 加入蘑菇。炒3分鐘，加入鹽和黑胡椒不時攪拌。取出備用。
5. 視狀況可再加少許奶油。放入牛肉翻炒至變色。
6. 再加入洋蔥、香腸翻炒。
7. 洋蔥軟化後，加入紅椒粉、番茄醬、香芹葉碎、鹽和黑胡椒翻炒。
8. 最後1分鐘時加入白酒，攪拌均勻。
9. 當特福智能萬用鍋發出提示音時，加入125ml的水。
10. 選擇「牛／羊」。設定時間30分鐘。蓋上上蓋並鎖緊。
11. 按「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
12. 當特福智能萬用鍋發出提示音時，完成洩壓後，按「取消」。打開上蓋。
13. 加入蘑菇，關上上蓋並鎖緊。
14. 選擇「自訂行程」。將溫度設定為70°C。設定時間5分鐘。
15. 按「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
16. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋。
17. 沾鮮奶油和芥末醬食用。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 牛肉可先沾少許麵粉，湯汁會較濃稠。
- 2. 可將芥末醬加入一起燉煮，而鮮奶油與蘑菇一起放。
- 3. 白酒也可使用白蘭地替代。
- 4. 牛肉也可使用牛腩替代。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`爆炒煎烤`（150°C，開蓋，預熱可長達 5 分鐘）須於開蓋狀態下進行，待預熱提示音響起後再下奶油與食材；`牛／羊`（預設 60kPa，30 分鐘）為增壓快煮行程，必須**蓋上上蓋並鎖緊**，倒數完成並**完成洩壓後**再按「取消」開蓋；最後一段 `自訂行程`（70°C，5 分鐘）為低溫無壓加熱，依步驟 13 關上上蓋並鎖緊燜熱蘑菇，結束後直接按「取消」即可開蓋。
- **烹調與護鍋提醒**：步驟 9 須額外加入 **125ml 清水**（未另列於上方食材表），請事前備妥以確保加壓燉煮具備足夠液體；全程翻炒請使用木杓或耐熱矽膠鍋鏟，保護不沾內鍋塗層。
