> **官方料理簡介**：沒有烤箱一樣能做燒雞。使用特福智能萬用鍋及簡單的中式香料--薑、蔥，就能做出完美的燒雞。不僅雞肉鮮嫩，雞汁也能大幅度保留，讓人吮指回味樂無窮～

---

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 雞（600g） | 1隻 |
| 米酒 | 100ml |
| 生抽 | 1tbsp |
| 老抽 | 1tbsp |
| 鹽（調味） | 適量 |
| 蜜糖 | 2tbsp |
| 薑片和青蔥（足以覆蓋鍋內底部） | 適量 |

---

## 二、製作步驟（官方原文逐步整理）

1. 雞洗淨，浸泡於米酒、生抽和蜜糖中，2小時。
2. 將雞擦乾。
3. 用薑和青蔥覆蓋內鍋底部。
4. 放上雞。
5. 關上上蓋但不要鎖上。
6. 選擇「自訂行程」模式，將溫度設定為120°C，時間設定為50分鐘。
7. 時間到打開上蓋。

---

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 要想顏色加深，可用蠔油＋老抽

### CY625870 實作操作重點
- **上蓋與洩壓確認**：本道使用「自訂行程」（可調範圍 60–150°C），設定 **120°C／50 分鐘**，並須**關上上蓋但不要鎖上**；全程為無壓烹調，時間到無需洩壓即可直接開蓋。
- **烹調與護鍋提醒**：因本道為無水料理，步驟 3 務必以薑片與青蔥鋪滿覆蓋整個內鍋底部，防止雞皮與蜜糖直接接觸鍋底燒焦沾黏；食材表中的老抽與鹽可於醃漬時調入，下鍋前確實將雞身表面擦乾較易上色。官方標示 50 分鐘不含前置 2 小時醃漬時間。
