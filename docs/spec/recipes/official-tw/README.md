### 原廠手冊使用與清潔安全提示（p.2、p.4–6）
1. 內鍋所裝食材與液體絕不可超過內鍋內側 `MAX` 刻度；煮粥或稀飯時，米與水高度不可超過 `MAX` 刻度的 `1/2`。
2. `中途加料` 適用於 `牛/羊`、`雞/鴨/豬`、`煮/燉湯品` 程式；烹調啟動後長按 `取消` 鍵可終止當前程式。
3. 清潔前至少冷卻 2 小時；**請勿將主機、內鍋、內蓋放入洗碗機**，請使用膠勺或木勺保護內鍋不沾塗層，並避免直接倒醋於內鍋久置；密封墊圈建議每 2 年更換。
