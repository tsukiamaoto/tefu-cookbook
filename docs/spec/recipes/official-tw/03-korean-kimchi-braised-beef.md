# 韓式泡菜燉牛肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 韓國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.13–14） |

> **官方料理簡介**：韓國媽媽人人拿手的家常菜餚。泡菜內所含的酵素可讓肉質軟嫩，熬煮而成的湯汁濃郁鮮香，酸甜微辣正是白飯的最佳拍檔!

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |

| 植物油 | 2tbsp |
| 紅洋蔥(去皮切絲) | 1顆 |
| 紅蘿蔔 (去皮切碎) | 1根 |
| 蒜泥 | 1tbsp |
| 薑泥 (去皮) | 1tbsp |

| 低鹽生抽 | 1/4杯 |

| 糖 | 1/4杯 |
| 韓式辣椒醬 | 2tbsp (按個人喜好) |

---

## 二、製作步驟（官方原文逐步整理）

1. 在內鍋中加入少量植物油。選擇「爆炒煎烤」功能，並將時間設定為 30分鐘，按「開始」。
2. 當特福智能萬用鍋發出提示音，表示油已燒熱。放入牛小排分批煎過。
3. 倒出多餘的油，加入洋蔥、紅蘿蔔、蒜和薑，炒約 5分鐘。
4. 加入麵粉翻炒，至所有材料均勻。按「取消」。
5. 倒入雞湯、生抽、泡菜、辣椒醬和糖，以鹽和黑胡椒調味拌勻。再放入牛小排。
6. 關上上蓋但不要鎖上。
7. 選擇「高溫慢燉」功能，設定時間8小時，按下「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒時開始倒數。
8. 當特福智能萬用鍋發出提示音時，按「取消」。打開上蓋。然後撒上蔥花和白芝麻。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 喜歡泡菜味重一些的，可增加到1/2杯。
- 2. 重度嗜辣者，可將麵粉改為韓式辣椒粉2tbsp。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：`爆炒煎烤`（150°C，開蓋，預熱可長達 5 分鐘）於開蓋狀態下分批煎肉與爆香，麵粉炒勻後直接按「取消」停止；`高溫慢燉`（90°C，8 小時）為無壓特殊行程，依原廠規格與步驟 6 須**關上上蓋但不要鎖上**，行程結束無須洩壓，按「取消」即可直接開蓋。
- **烹調與護鍋提醒**：步驟 4 拌入麵粉翻炒後，於步驟 5 加入雞湯與韓式辣椒醬時務必以耐熱矽膠鏟將鍋底麵粉與醬料徹底拌開，避免 8 小時慢燉期間沉底結塊；煎肉後依步驟 3 倒出多餘油脂時請小心鍋體高溫燙手。
