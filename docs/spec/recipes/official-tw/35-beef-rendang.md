# 巴東牛肉

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 印尼 |

| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 40 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `牛/羊` |
| 完整行程串接 | `爆炒煎烤`（開蓋，150°C，設定 15 分鐘；炒洋蔥、薑泥、蒜泥 1 分鐘＋炒巴東咖哩醬 2 分鐘＋炒牛肋條約 4 分鐘＋加 1/2 杯水煮至完全收乾＋拌入椰漿後取消） → `牛/羊`（鎖蓋，預設 60kPa，設定 30 分鐘，完成並排氣洩壓後開蓋） →（選用）`收汁/醬燒`（開蓋，110°C，5–8 分鐘） |

> **官方料理簡介**：巴東牛肉又稱為仁當牛肉，牛肉經過長久燉煮後，吸滿了香料和椰奶的精華。辣椒、香料、椰奶和牛肉油脂混合後流露出鮮橘色膏油，是道充滿致命吸引力的印尼料理。

| --- | --- |
| 牛肋條 (切成約3cm大小) | 750g |

| 薑泥 | 1tbsp |
| 蒜泥 | 1tbsp |
| 小辣椒(按個人喜好) | 1根 |
| 植物油 | 1tbsp |
| 巴東咖哩醬 | 30g |
| 全脂椰漿 | 1杯 |
| 水 | 1/2杯 |
| 椰絲 | 2tbsp |

---

## 二、製作步驟（官方原文逐步整理）

1. 內鍋中加入少許植物油。選擇「爆炒煎烤」模式。將時間設定為15分鐘。
2. 當特福智能萬用鍋發出提示音時，油已熱，隨即可加入洋蔥、薑泥、蒜泥翻炒1分鐘。
3. 加入巴東咖哩醬並不斷翻炒。煮2分鐘。
4. 加入牛肋條，然後炒約4分鐘。
5. 加入1/2杯水，拌勻然後煮至水分完全收乾。加入椰漿並拌勻。
6. 取消「爆炒煎烤」功能。關上上蓋並鎖緊。
7. 選擇「牛/羊」，將時間設定為30分鐘，然後按下「開始」。
8. 當模式完成並排氣洩壓後，打開上蓋，檢查醬汁的濃度。如果希望令醬汁變得濃稠，選擇「收汁/醬燒」功能，在上蓋打開情況下讓醬汁蒸發5-8分鐘，直至達到理想的濃稠度。(請注意，醬汁冷卻後會變得更濃稠)。
9. 撒上椰絲做裝飾，並淋於飯上享用。

## 三、官方小撇步！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 可使用市售巴東咖哩醬包
- 2. 牛肋條可先用巴東醬醃漬一晚，會更入味。
- 3. 步驟 5 要水分完全收乾後，再加入椰漿。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：「爆炒煎烤」（150°C，預熱可長達 5 分鐘）與最後選用的「收汁/醬燒」（110°C）皆須**開蓋**操作，結束爆炒須先按「取消」；「牛/羊」增壓快煮（預設 60kPa／30 分鐘）階段須**關上上蓋並鎖緊**，完成後待排氣洩壓完畢再打開上蓋。
- **烹調與護鍋提醒**：務必依官方小撇步 於步驟 5 先將水分完全收乾後再拌入全脂椰漿；因香料醬與椰漿濃稠度高，翻炒與收汁 5–8 分鐘期間建議以矽膠或木質鍋鏟持續輕拌防黏底，並留意醬汁冷卻後會更濃稠，切忌收得過乾；若加入小辣椒可視個人嗜辣程度於爆香辛香料時一同下鍋。
