# 巧克力香草大理石磅蛋糕

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 美國 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.65–66） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 59 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `烘烤` |
| 完整行程串接 | `烘烤`（無壓行程 120–150°C，蓋上不鎖，設定 59 分鐘） |

> **官方料理簡介**：美式家庭聚會必不可少的甜點。融合了香草與巧克力的香氣，濃郁奶香及細緻地質地，加上大理石般堆疊的紋路，是種低調奢華的美味。

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 鹽奶油 | 150g |
| 紅砂糖 | 150g |
| 蛋 | 3顆 |
| 中筋麵粉 | 150g |
| 泡打粉 | 1tsp |
| 可可粉 | 1tbsp |
| 檸檬汁 | 1tbsp |
| 香草莢 | 1根 |
| 牛奶（全麵糊） | 35ml |
| 牛奶（可可麵糊） | 30ml |

---

## 二、製作步驟（官方原文逐步整理）

1. 奶油與糖打發至泛白。
2. 加入一顆雞蛋，攪拌至完全融合再加入下一顆，重複至三顆雞蛋完全加入。
3. 再放入檸檬汁、牛奶35ml和香草籽拌勻。
4. 加入麵粉和泡打粉，攪拌至材料完全融合。
5. 取1/3麵糊加入可可粉再加牛奶2tbsp(約30ml)，攪拌均勻。
6. 將可可口味麵糊倒回香草麵糊中，稍微攪拌幾次，不須拌勻。
7. 內鍋底部鋪上烘焙紙，將麵糊一一挖入內鍋。
8. 關上上蓋但不要鎖上。
9. 選擇「烘烤」。將時間設定為59分鐘。
10. 按「開始」。畫面會顯示打圈轉動的圖案，並會在準備就緒開始倒數。
11. 當特福智能萬用鍋發出提示音，打開上蓋。
12. 取出內鍋，冷卻至微溫後，用鍋鏟輕刮蛋糕邊緣，再將蛋糕倒扣出來。
13. 可用巧克力覆蓋蛋糕，再用巧克力糖做裝飾。

## 三、官方 Tips！與 CY625870 操作提醒

### 官方手冊 Tips！
- 1. 蛋糕完全冷卻後，可用保鮮膜包覆，於冰箱冷藏一晚再享用，風味更佳。
- 2. 不喜過甜者，砂糖可減至80g
- 3. 上菜時還可另外加上一球香草冰淇淋，更添美式風味。

### CY625870 實作操作重點
- **上蓋與洩壓確認**：「烘烤」屬於左側無壓特殊行程（120–150°C），操作時務必依步驟 8 **關上上蓋但不要鎖上**。全程不加壓，提示音響起即可直接打開上蓋，無須洩壓等待。
- **烹調與護鍋提醒**：麵糊入鍋前在內鍋底部鋪設烘焙紙可避免沾黏並方便脫模；取出高溫內鍋請配戴隔熱手套，冷卻至微溫後使用矽膠刮刀或非金屬鍋鏟輕刮蛋糕邊緣，保護球釜不沾內鍋塗層。
