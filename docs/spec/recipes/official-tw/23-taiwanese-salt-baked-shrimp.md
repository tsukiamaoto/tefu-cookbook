# 台式鹽焗蝦

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 台灣 |
| 官方來源 | [法國特福台灣官方《鮮呼吸智能萬用鍋 36 道世界料理食譜》](https://www.tefal-home.com.tw/recipe/SMARTPROEPC/)（手冊編號 `1520010597-02`，p.53–54） |
| 適用機型 | **Tefal 特福鮮呼吸智能萬用鍋 CY625870** |
| 官方標示時間 | 25 分鐘 |
| 官方份量 | 4 人份 |
| 官方主打模式 | `自訂行程` |
| 完整行程串接 | `自訂行程`（110°C，25 分鐘，關上上蓋不鎖上；小型蝦改設 15 分鐘） |

> **官方料理簡介**：使用傳統烹飪技法「焗」，讓蝦子被高溫的鹽鎖住鮮甜，做出來的蝦子外殼紅亮，原汁原味的鮮香，蝦肉更是爽脆彈牙。

## 一、食材清單（官方原文配方）

| 食材 | 份量 |
| --- | --- |
| 草蝦（大） | 250g |
| 薑片、青蔥 | 各5g |
| 海鹽 | 500g |
| 米酒 | 5ml |
| 檸檬 | 1顆 |

---

## 二、製作步驟（官方原文逐步整理）

1. 蝦洗淨，浸泡於米酒和檸檬汁中。
2. 用海鹽覆蓋內鍋。
3. 將蝦、薑和青蔥放在鹽上。
4. 上層再撒上少量鹽。
5. 關上上蓋但不要鎖上。
6. 選擇「自訂行程」模式，將溫度設定為110°C，時間設定為25分鐘。
7. 時間到打開上蓋。

---

## 三、官方小撇步！與 CY625870 操作提醒

### 官方手冊 Tips！
- 小型蝦 15分鐘

### CY625870 實作操作重點
- **上蓋與洩壓確認**：使用「自訂行程」（可調範圍 60–150°C），設定 **110°C／25 分鐘**（若為小型蝦依官方小撇步 調整為 **15 分鐘**），操作時須**關上上蓋但不要鎖上**，屬無壓烹調，時間到可直接開蓋。
- **烹調與護鍋提醒**：鋪放海鹽與取蝦時動作宜輕，避免粗鹽顆粒大力摩擦刮傷內鍋不沾塗層；烹調完成並待內鍋降溫後，請以清水沖泡溶解殘鹽並立即清洗擦乾，避免高鹽分久留內鍋。
