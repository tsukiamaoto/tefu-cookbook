# 破布子清蒸魚（樹子鮮魚零油煙版）

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 台灣（家常蒸菜） |
| 份量基準 | 4 人份 |
| 食譜來源 | [電鍋破布子蒸魚｜愛料理](https://icook.tw/recipes/454765) |
| 預估總耗時 | 18 分鐘（含升壓約 7 分＋微壓蒸 8 分＋自然洩壓約 3 分） |
| CY625870 建議模式 | `蒸／一鍋兩菜` 8 分鐘（鎖蓋＋自然自動洩壓） |

---

## 一、食譜準備

### 主材料（4 人份）
- 鮮魚片（鱈魚片／鯛魚片，或整尾中型鱸魚洗淨擦乾）：450 公克（約 2 片厚鱈魚或 1 尾整魚，確認可平放入內鍋）
- 罐頭破布子（樹子，含果粒）：2 大匙
- 老薑：4 片（切細絲）
- 青蔥：2 支（切段或切蔥絲，蔥白墊底、蔥綠起鍋撒）

### 調味料與液體
- 破布子罐頭原汁：2 大匙（自帶甘鹹味）
- 米酒：1.5 大匙（去腥提鮮）
- 醬油（選配）：1 小匙（若破布子偏鹹可省去）
- 細砂糖（選配）：0.5 小匙（帶出甘醇回味）
- 底鍋蒸水：1 米杯（約 200 毫升溫水，水位低於蒸架面）

### 器具建議
- 陶晶球釜內鍋或 304 不鏽鋼內鍋皆可，搭配原廠蒸架與直徑約 18–20 公分耐熱瓷盤。

---

## 二、簡單實作步驟

1. **魚身擦乾抹米酒，鋪上薑絲與破布子**：鮮魚洗淨後用廚房紙巾壓乾表面水分（去腥關鍵；若是厚整尾魚可在魚背斜劃 2 刀）。耐熱瓷盤底先鋪蔥白段與一半薑絲架高魚身，放上鮮魚，淋入米酒、破布子連同 2 大匙原汁（可視鹹淡補 1 小匙醬油與少許糖），再撒上剩餘薑絲。
2. **鍋底加水架蒸架，鎖蓋選「蒸／一鍋兩菜」預設 8 分鐘**：內鍋底倒入 1 米杯溫水放上原廠蒸架，平穩放入魚盤。蓋上鍋蓋並將上蓋手把順時鐘轉到底鎖定，按面板右側 **`蒸／一鍋兩菜`**，直接維持預設 **8 分鐘**按下開始。
3. **安全閥一落下立刻開蓋起鍋**：微壓行程洩壓很快，安全閥一落下立刻將鍋蓋朝遠離身體方向打開，用筷子戳魚身最厚處能輕鬆穿透即熟，撒上蔥綠絲用防燙取盤夾端出上桌。

## 四、新手撇步與避坑提醒

- **魚身一定要先擦乾再淋米酒**：殘留血水與水分是魚腥味主要來源，紙巾壓乾後再墊蔥薑、淋米酒與破布子，蒸出來完全無腥味。
- **時間一到別悶在鍋裡**：蒸魚最怕餘溫悶老，安全閥一落下就馬上開蓋取出，魚肉才會水嫩彈口。
- **破布子本身已有鹹度**：各品牌破布子鹹甜度不同，新手建議先靠破布子原汁＋米酒調味即可，不怕死鹹。
