# 古早味菜頭排骨湯（白蘿蔔貢丸湯）

| 項目 | 內容 |
| --- | --- |
| 國家／菜系 | 台灣（家常清湯） |
| 份量基準 | 4 人份 |
| 食譜來源 | [白蘿蔔排骨貢丸湯｜愛料理](https://icook.tw/recipes/365472) |
| 預估總耗時 | 48 分鐘（含升壓約 13 分＋壓力 20 分＋自然洩壓約 15 分） |
| CY625870 建議模式 | `煮／燉湯品` 20 分鐘（鎖蓋＋自然自動洩壓） |

---

## 一、食譜準備

### 主材料（4 人份）
- 白蘿蔔（菜頭）：600 公克（約中型 1 條，厚削去皮切 3–4 公分大塊）
- 豬小排或軟骨排：400 公克（先冷水汆燙洗淨血水）
- 貢丸：8 顆（選配，表面可劃十字更入味）
- 老薑：4 片（去腥提鮮）
- 芹菜末或香菜末：2 大匙（起鍋撒香用）

### 調味料與液體
- 清水：1300 毫升（約 7 米杯，淹過食材且勿超最高水位線）
- 米酒：1 大匙
- 鹽：1 小匙（開蓋後試味微調）
- 白胡椒粉：適量（起鍋提香）

### 器具建議
- 建議優先使用 **304 不鏽鋼內鍋**（排骨硬骨不怕刮傷塗層）；若用標配陶晶球釜內鍋，請輕放排骨並使用矽膠湯勺。

---

## 二、簡單實作步驟

1. **排骨冷水汆燙、白蘿蔔厚削皮切大塊**：將排骨放進冷水鍋（或用內鍋開蓋煮滾）煮沸約 2 分鐘逼出灰白血沫，撈出用清水沖乾淨備用；白蘿蔔把表皮**連同內層帶筋的白皮厚削一層**才不帶苦澀，再切成約 3–4 公分大塊。將排骨、白蘿蔔、薑片、米酒與 1300 毫升清水入鍋（水位不超過最高水位線）。
2. **鎖蓋選「煮／燉湯品」直接壓 20 分鐘**：蓋上鍋蓋並將上蓋手把順時鐘轉到底鎖定，按面板右側 **`煮／燉湯品`**，直接維持預設 **20 分鐘**按下開始。行程結束靜待自然自動洩壓、安全閥完全落下再開蓋。
3. **開蓋放貢丸與調味撒芹菜末**：確認安全閥落下後將鍋蓋朝遠離身體方向傾斜打開，加入鹽與白胡椒粉拌勻、撒上芹菜末或香菜末即可上桌。若有加貢丸，可於開蓋後丟入貢丸、按左側 **`收汁／醬燒`** 煮滾約 3 分鐘後按取消，貢丸最 Q 彈不脹爛。

## 四、新手撇步與避坑提醒

- **排骨「冷水下鍋汆燙」湯才會清澈**：熱水直接燙會把血水鎖在骨頭裡，讓湯頭混濁帶腥；冷水慢煮至大滾再沖洗，湯底立刻像小吃店一樣清甜透亮。
- **白蘿蔔皮要削厚一點**：白蘿蔔皮下有一層白筋最容易帶辛辣苦味，多削 1–2 毫米（或削皮刀同處多削一次），燉出來的菜頭湯自然回甘。
- **起鍋前才下鹽與白胡椒**：提早加鹽容易讓肉質偏緊，洩壓開蓋後再依口味補鹽、撒白胡椒與芹菜末香氣最足。
