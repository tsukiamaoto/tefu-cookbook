## 二、簡單實作步驟（逐字稿＋畫面補充）

1. **泡軟冬粉**（約 `[01:11]`）：事前先將韓式冬粉泡水至軟化，下鍋前瀝乾水分。
2. **開蓋爆炒牛肉**（`[03:53]`–`[04:07]`）：依法式智能壓力鍋螢幕引導保持**解鎖開蓋**（`[04:07]` 畫面提示「請解開上蓋鎖定」）；於 CY625870 選擇左側無壓模式 **`爆炒煎烤`**（開蓋，150°C），鍋熱後倒入食用油，放入牛肉絲炒至變色出香。
3. **放入蔬菜、冬粉、醬料與水**（`[04:07]`–`[04:21]`）：先取消爆炒模式，將切絲蔬菜、泡軟的冬粉、調味料與適量清水一併放入鍋中（建議冬粉鋪在液體與蔬菜間，避免乾貼鍋底）。
4. **鎖蓋高壓快煮 3 分鐘**（`[04:21]`）：將上蓋手把**順時鐘轉到底鎖定**，確認啟動壓力烹調（`[04:21]` 螢幕顯示「是否開始壓力烹調？是」）設定 **3 分鐘**（CY625870 可選右側最短壓力行程或手動調至最低可設分鐘數並留意開蓋時機）。
5. **洩壓開蓋立刻拌鬆與撒芝麻**（`[04:35]`–`[04:49]`）：壓力行程結束後洩壓解鎖開蓋（開蓋防燙水），畫面 `[04:35]` 可見此時鍋內湯汁已近乎被冬粉吸乾無多餘積水，立刻用矽膠勺由鍋底將冬粉、牛肉絲與五色蔬菜充分翻拌均勻；盛盤後**於表層豪邁撒上白芝麻**（`[04:49]`）即可上桌，成品冬粉呈油亮深琥珀色、根根分明不結團。

## 四、影片小撇步與 CY625870 轉譯提醒

- **原片實戰技巧**：
  - 傳統韓式雜菜需要分開炒洋蔥、紅蘿蔔、菠菜、肉絲再煮冬粉，工序極繁瑣；透過萬用鍋「先炒肉 ➔ 全部下鍋高壓 **3 分鐘**」，一鍋到底就能快速完成，省下大量洗鍋與炒菜時間。
  - 冬粉**一定要提前泡水軟化**，否則 3 分鐘壓力無法完全煮透。
- **CY625870 對應注意**：
  - **時間下限轉譯**：CY625870 部分右側壓力行程與自訂行程（最低 5 分鐘且一啟動即倒數不含升壓）之分鐘設定與法式智能壓力鍋的「精準 3 分鐘」略有不同；操作時建議**改加溫熱水加快升壓**，並在壓力烹調完成後**盡快排氣開蓋**，避免過度自然悶壓造成地瓜冬粉過爛坨成一團。
  - **澱粉防黏與防噴漿**：冬粉含高澱粉，鍋內水量切忌過高（絕不超過內鍋 1/2），且拌料時確保底部有液體浸潤，可大幅減少沾底風險。
  - **容量提醒**：原片提到法式智能壓力鍋 6L 內鍋可一次做 6 人份以上，CY625870 為 **5L 內鍋**，建議以 **2–4 人份**為最佳翻拌份量。
